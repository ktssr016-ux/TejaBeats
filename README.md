## 🔥 Key Features

- 🚫 **Ad-Free & Unlimited Streaming:** Enjoy uninterrupted music with dynamic discovery & search.
- ⚡ **Supercharged Search Engine:** Instant query resolution powered by high-speed content plugins.
- 🎧 **Modern TejaBeats UI:** Dark mode aesthetic (`#0A060E` & `#FF2D78` accent) with glowing 3D visualizers.
- 📱 **Cross-Platform Excellence:** Native support for Windows Desktop and Android Mobile with responsive gestures.
- 🎶 **Dynamic Playlists & Favorites:** Create custom playlists, mark tracks as Liked Songs (`My Favourites`), and organize your library.
- 🎤 **Karaoke Lyrics & Equalizer:** Real-time synchronized lyrics display with built-in audio equalizer and crossfader.
- 🔄 **In-App Live Updates:** Built-in auto update checker for hassle-free one-click updates.

## 🛠️ Build & Development Setup

### Prerequisites
- [Flutter SDK](https://flutter.dev/docs/get-started/install) (v3.19.0 or higher)
- [Rust Toolchain](https://www.rust-lang.org/tools/install) (for `flutter_rust_bridge`)

### Run Locally
```bash
git clone https://github.com/ktssr016-ux/TejaBeats.git
cd TejaBeats
flutter pub get
flutter run -d windows
```

### Build Releases
- **Windows Executable**:
  ```bash
  flutter build windows --release
  ```
- **Android APK**:
  ```bash
  flutter build apk --release
  ```
